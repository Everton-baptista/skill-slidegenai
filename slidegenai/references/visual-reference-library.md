# Executable visual references

For a modern, expressive or named-style request, inspect a relevant rendered reference before extending a default layout. These resources preserve artwork, content and measured geometry from the existing fictitious style studies. They make the visual standard observable: image direction, live type scale, protected reading regions and an evidence page belonging to the same visual language.

Read `assets/style-references/manifest.json` for the nine reference IDs, image hashes and translation limits. Open the selected local JPEG to understand its actual subject/negative space; inspect or render the matching plan to see the text and evidence separately. Load only the relevant pair, not all resources. They are examples within the 177-entry catalog, not the only supported styles.

From the installed skill folder, reproduce an existing reference pair:

```sh
node assets/visual-kit/build.mjs \
  --plan assets/style-references/fashion-editorial.plan.json \
  --design assets/style-references/fashion-editorial.design.json \
  --visuals assets/style-references/fashion-editorial.visuals.json \
  --format html --out /work/nova-reference
```

Use a new output directory outside the installed skill. Open presentation.html, wait for fonts/images, then inspect both slides at reading size and in overview. The source title NOVA is deliberately large; a small font that fits the box but loses the intended hierarchy is a failed reproduction. Geometry checks alone cannot make that decision.

The reference fragments include Acid Rave, Neo-Tech, Cyberpunk, NOVA, Ultimate Luxury, Neo Tokyo, Bauhaus, Kinetic and Corporate & Education. All type remains live, images are separate, and chart/table data is structured. Original concept imagery was JPEG-optimized and bundled fonts replace earlier local faces. Two-stop reading gradients approximate the original overlays. These are creative studies, not official brand masters or affiliations.

Use the relationship, not a compulsory copy. A new brief needs its own relevant imagery, actual content and composition choices. Do not reuse a fashion model, neon city or hospitality concept as unrelated filler. Do not flatten the finished slide into an image. Keep supplied identity and exact-template requirements above catalog treatments. The reference image is illustrative concept artwork, not documentary photography.

For a creative starting system on any catalog ID, see `catalog_treatment` in [the visual kit](visual-kit.md#catalog-character-and-composition). This connects the style to geometry, typography and analytical objects. The reference fragments can also be adapted with explicit measured elements when the starting recipe is too generic. Judge the actual rendered cover and evidence page together; a beautiful cover followed by an unrelated default chart or table is incomplete art direction.
