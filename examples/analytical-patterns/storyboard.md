# Analytical construction storyboard

All data, relationships and dates are fictional. The common study frame deliberately repeats so readers can compare evidence structures.

1. **Completed items by region** — Comparable categories, two periods and a zero baseline.
2. **Delivery time over six months** — Two series, a shared time scale and explicit units.
3. **Channel mix** — Each quarter represents the same whole: 100%.
4. **Training and output** — Paired observations. Association does not establish causation.
5. **Decision and rework** — A decision needs both destinations and a visible return path.
6. **Responsibility and handoffs** — Lane membership expresses ownership. Arrows express handoffs.
7. **System relationships** — An asynchronous path and a distinct read connection.
8. **Roadmap with real durations** — Jan–Jun 2027. Bar widths follow elapsed days, not equal visual slots.
9. **Categorical risk matrix** — Qualitative placements for a fictional assessment, not numeric probabilities.
10. **Decision criteria** — A comparison preserves common criteria and explicit tradeoffs.
