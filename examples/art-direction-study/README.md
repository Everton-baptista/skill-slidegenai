# One subject, three visual arguments

This study applies the skill's art-direction process to the same fictional room image and observable features: a shared table, books within reach, and daylight from the side. It does not claim that the room improves learning. The image comes from the existing fictional portable-deck example and is intentionally reused here for a controlled comparison.

Open [study.html](study.html) locally, or inspect the [overview](previews/overview.png). No build step, network access, image generation, or provider key is needed. The HTML uses local assets and system-font fallbacks.

## The decisions

| Brief | Visual argument | Why this treatment |
| --- | --- | --- |
| Analytical observation | Clear subject heading, aligned facts, a readable documentary image | Readers need to inspect the visible evidence; irregular data placement would make that harder |
| Editorial proposition | Large serif statement on a stable dark field, full-height photographic crop | The presentation is about a place and an interpretive proposition; the photograph carries context |
| Human-scale observation | Gentle type cadence, an offset image, generous uneven whitespace, one softened image edge | A softer register is appropriate to the brief; logos/evidence would still remain precise |

These are three alternative briefs, not three styles to mix mechanically into every deck. The same factual anchors remain present. Typeface, palette, and masking freedom are permitted in these explicitly fictional studies; a real reference may prohibit those changes. No original logo is recolored or distorted.

The organic option uses one restrained edge treatment and spacing relationship rather than scattered decorative blobs. Its radius is an example choice, not a required component or a new organic preset. A real architectural, ecological, or human subject may suggest a completely different gesture—or none.

See the [briefs and decisions](briefs.json) and [inspection record](review.json). These are optional art-direction working records, not a replacement for a complete deck plan.

## Boundaries

The PNGs are browser renderings of these HTML compositions, not native PowerPoint exports. Native table/chart examples remain in the separate eight-slide editable deck. A PPTX adapter must reproduce or simplify the softened image edge deliberately, preserve editable text, and inspect the actual export.

The text in this study is an editorial proposition and observations of a generated image. It contains no invented quotation, handwriting, measured effect, or testimonial. No claim of total originality, human authorship, automatic beauty assessment, or AI detection is made.
